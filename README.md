## About

## Apps & Websites

- **[Always Yesterday Party](https://alwaysyesterday.party/)** — 自主レーベルの公式サイト。
  [Source](https://github.com/nsh1l/ayp-site)
- **[SONORA](https://sonora.alwaysyesterday.party/)** — ローカル音源を再生し、音に応じた映像を表示するオーディオビジュアライザー。
  [Source](https://github.com/nsh1l/sonora)
- **[AYP TrackID](https://trackid.alwaysyesterday.party/)** — 再生画面のスクリーンショットから曲名・アーティストを読み取り、音楽配信サービスのリンクを探すアプリ。
  [Source](https://github.com/nsh1l/w-sc2link)
- **[void series](https://void.alwaysyesterday.party/)**
- **[あわわ](https://awawa.alwaysyesterday.party/)** — 入力した文章を泡のアニメーションで表示し、消去するWebアプリ。文章の送信・保存はしません。
  [Source](https://github.com/nsh1l/awawa)
- **[soichi.ro](https://soichi.ro/)** — ドメインハック
